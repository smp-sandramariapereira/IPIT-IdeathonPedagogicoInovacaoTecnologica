# Kit da turma
**Projeto ou código da equipe:** ______
Use códigos nas versões públicas. Identificação pessoal, quando necessária à avaliação, fica no registro interno do professor.
Combinem: todos participam das decisões, tarefas são distribuídas e o resultado é revisado em conjunto.

## 1. Investigar — ficha do problema
- Quem enfrenta o problema? ______
- Em qual situação ele acontece? ______
- Problema em uma frase: ______
- Evidência disponível e sua origem: ______
- O que é hipótese e ainda precisa ser verificado? ______
- Que melhoria seria importante para esse público? ______

Não inventem entrevistas, observações ou números. Identifiquem dados simulados.

## 3. Prototipar — representação do funcionamento
Construam somente o fluxo principal usando ferramenta conhecida ou representação em papel.
- Entrada (o que o usuário informa ou faz): ______
- Regra/processamento (o que a solução faz): ______
- Saída (o que o usuário recebe): ______
- Sequência de telas, ações ou passos: ______
- Dados fictícios utilizados: ______
- Como uma pessoa com necessidades diferentes poderá participar? ______
- Arquivo ou descrição do protótipo: ______

Se usarem IA, preencham o [registro breve](../docs/tecnologias-e-ia.md). Não apresentem conteúdo gerado sem compreender e verificar.

## 4. Testar e melhorar
Peçam a um colega de outra equipe para realizar uma tarefa. Observem antes de explicar.
| Registro | Preencher |
|---|---|
| Tarefa proposta | |
| Resultado esperado | |
| O que aconteceu | |
| Dificuldade ou feedback | |
| Mudança realizada, ou justificativa para manter | |
| Resultado do novo teste, se realizado | |

O teste com colega é uma verificação inicial; não comprova aceitação pelo público real.

## 5. Apresentar — até quatro minutos
1. Problema, público e evidência.
2. Solução e justificativa do recurso tecnológico.
3. Demonstração do fluxo.
4. Teste, mudança, limitação e aprendizagem.

No feedback, indiquem um ponto claro e uma pergunta ou melhoria respeitosa. Finalizem com a [reflexão](avaliacao-e-reflexao.md).
